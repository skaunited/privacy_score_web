# Astro Builder Skill — privacyscore.fr

You are an expert Astro 6.x developer building the privacyscore.fr marketing site. The site is **static-first**, **SEO-first**, **FR+EN bilingual**, and **zero-runtime-JS by default**.

## Core principles (non-negotiable for this project)

1. **Static output (SSG)** — `output: 'static'` in `astro.config.mjs`. No SSR, no adapter, no server functions.
2. **Zero JavaScript by default** — Only add `client:*` directives when a component genuinely needs interactivity. Prefer CSS over JS.
3. **i18n via Astro built-in** — `/fr/` (default) and `/en/` subdirectories. Never use `astro-i18next` (archived).
4. **Image optimization** — Always use Astro's built-in `<Image />` or `<Picture />`. Never `<img>` for content images.
5. **Content Collections** — Use the Content Layer API (`src/content.config.ts`) for blog posts, FAQ entries, anything structured.
6. **Type-safe** — Strict TypeScript. `astro check` must pass before any commit.

## Required astro.config.mjs

```js
import { defineConfig } from 'astro/config';
import sitemap from '@astrojs/sitemap';
import mdx from '@astrojs/mdx';
import tailwind from '@astrojs/tailwind';
import robotsTxt from 'astro-robots-txt';

export default defineConfig({
  site: 'https://privacyscore.fr',
  output: 'static',
  trailingSlash: 'never',
  build: {
    inlineStylesheets: 'auto',
  },
  prefetch: {
    prefetchAll: true,
    defaultStrategy: 'viewport',
  },
  i18n: {
    defaultLocale: 'fr',
    locales: ['fr', 'en'],
    routing: {
      prefixDefaultLocale: true,  // /fr/ AND /en/, never bare /
      redirectToDefaultLocale: true,
    },
  },
  integrations: [
    sitemap({
      i18n: {
        defaultLocale: 'fr',
        locales: { fr: 'fr-FR', en: 'en-US' },
      },
    }),
    mdx(),
    tailwind({ applyBaseStyles: false }),
    robotsTxt({
      sitemap: 'https://privacyscore.fr/sitemap-index.xml',
      policy: [{ userAgent: '*', allow: '/' }],
    }),
  ],
});
```

## Content Collections (Astro 6.x Content Layer API)

`src/content.config.ts`:

```ts
import { defineCollection, z } from 'astro:content';
import { glob } from 'astro/loaders';

const blog = defineCollection({
  loader: glob({ pattern: '**/*.{md,mdx}', base: './src/content/blog' }),
  schema: ({ image }) => z.object({
    title: z.string().max(60),
    description: z.string().max(160),
    publishDate: z.coerce.date(),
    updatedDate: z.coerce.date().optional(),
    heroImage: image(),
    heroImageAlt: z.string(),
    tags: z.array(z.string()),
    author: z.string().default('Skander Bahri'),
    lang: z.enum(['fr', 'en']),
    canonicalUrl: z.string().url().optional(),
  }),
});

const faq = defineCollection({
  loader: glob({ pattern: '**/*.{md,mdx}', base: './src/content/faq' }),
  schema: z.object({
    question: z.string(),
    answer: z.string(),
    category: z.enum(['general', 'privacy', 'technical', 'pricing']),
    order: z.number(),
    lang: z.enum(['fr', 'en']),
  }),
});

export const collections = { blog, faq };
```

## Partial hydration decision matrix

| Directive | When to use | Example |
|---|---|---|
| **NONE (default)** | Static content, no interactivity | 95% of marketing site components |
| `client:idle` | Below-the-fold widgets that aren't critical | Newsletter signup form footer |
| `client:visible` | Below-the-fold interactive widgets | Animated stats counter |
| `client:media="(min-width: 768px)"` | Interactive only on desktop | Desktop menu mega-dropdown |
| `client:load` | Above-the-fold critical interactivity | App store badge tracker (rare) |
| `client:only="react"` | Components that can't SSR | Third-party React widgets |

**Default for this project: NO directive.** If you're tempted to add one, justify it.

## Image rules (CRITICAL for Core Web Vitals)

ALWAYS:
- Import images, then pass to `<Image />`: `import hero from '../assets/hero.png'`
- Provide `width`, `height`, `alt`
- Use `loading="eager"` only for above-the-fold hero images
- Use `loading="lazy"` for everything else
- Provide `format={['avif', 'webp']}` for content images
- Provide `densities={[1, 2]}` for retina

```astro
---
import { Image } from 'astro:assets';
import hero from '../assets/hero.png';
---
<Image src={hero} alt="Tableau de bord Privacy Score" width={1200} height={630}
  format={['avif', 'webp']} loading="eager" />
```

## Common Astro 6.x pitfalls to avoid

1. ❌ Using `<img src="/some.png">` — bypasses optimization
2. ❌ Forgetting `astro check` before commit — TypeScript errors silently propagate
3. ❌ `client:load` on every island — kills the zero-JS advantage
4. ❌ Importing components from `node_modules` without `client:` directive when they need JS
5. ❌ Forgetting `trailingSlash: 'never'` — causes redirect loops on Nginx
6. ❌ JSON-LD via JavaScript injection — Google takes longer to process it. Use `set:html={JSON.stringify(jsonLd)}` in SSR HTML.
