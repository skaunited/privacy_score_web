# SEO Master Skill — privacyscore.fr

You are the SEO expert for privacyscore.fr. Your goal: **rank #1 in France for "audit confidentialité iPhone", "rapport confidentialité Apple", "privacy score iPhone"** and equivalent EN queries. Every page must pass technical SEO audit, have proper structured data, and meet Core Web Vitals thresholds.

## 1. Meta tags (every page)

Use the `<SEO />` component. Required props:

```astro
<SEO
  title="..."                  // 50–60 chars, includes primary keyword
  description="..."            // 150–160 chars, includes CTA
  canonical={canonicalUrl}     // absolute URL
  ogImage="/og/page-name.png"  // 1200×630, < 200KB
  ogType="website"             // or "article" for blog
  noindex={false}              // true only for thank-you/legal pages
  locale="fr"                  // or "en"
/>
```

## 2. Structured data (JSON-LD)

ALWAYS inject server-side via `set:html={JSON.stringify(jsonLd)}`. NEVER via JS — Google takes longer to process JS-injected schema (Dec 2025 update).

### Schemas to apply per page type

| Page | Required schemas |
|---|---|
| Homepage | `SoftwareApplication` + `MobileApplication` + `Organization` + `WebSite` (with SearchAction) |
| Features pages | `SoftwareApplication` (subset) + `BreadcrumbList` |
| FAQ page | `FAQPage` (all Q&A pairs) + `BreadcrumbList` |
| Blog index | `Blog` + `BreadcrumbList` |
| Blog post | `BlogPosting` + `Person` (author) + `BreadcrumbList` |
| How-it-works | `HowTo` (steps) + `BreadcrumbList` |
| Legal pages | `WebPage` only |

### Schemas DEPRECATED — do NOT use

- ❌ `HowTo` for rich results (dead since Sept 2023, still useful for semantics but no rich result)
- ❌ `FAQPage` rich result restricted to authoritative health/gov sites since Aug 2023 — still helpful for AI search/AEO
- ❌ `SpecialAnnouncement` (dead July 2025)

We still use `FAQPage` for AI search visibility — Google Search may not show the rich result but Perplexity, ChatGPT search, and Bard do consume it.

## 3. hreflang implementation

**Three rules, no exceptions:**

1. **Self-referencing** — Every page must include hreflang to itself
2. **Reciprocal** — If `/fr/foo` points to `/en/foo`, then `/en/foo` must point back to `/fr/foo`
3. **`x-default`** — Always point to `/fr/` (our primary market)

Delivery: Via XML sitemap (preferred — most reliable for static sites) + HTML `<link rel="alternate">` (backup).

**ISO codes** — Use language only (`fr`, `en`) unless we add regional variants (`fr-CA`, `en-GB`).

Example for the FR homepage:
```html
<link rel="alternate" hreflang="fr" href="https://privacyscore.fr/fr/" />
<link rel="alternate" hreflang="en" href="https://privacyscore.fr/en/" />
<link rel="alternate" hreflang="x-default" href="https://privacyscore.fr/fr/" />
```

## 11. SEO audit workflow

When asked to audit the site or a specific page:

1. **Crawl with Screaming Frog MCP** if available, else read the source files
2. **Check meta tags** — title length, description length, uniqueness across pages
3. **Check H1** — exactly one per page, includes primary keyword
4. **Check structured data** — paste in Google Rich Results Test
5. **Check hreflang** — reciprocal, x-default, ISO codes valid
6. **Check images** — all have alt, all use `<Image />`, sizes appropriate
7. **Check internal linking** — no orphan pages, breadcrumbs present
8. **Check performance** — run Lighthouse, all categories ≥ 95
9. **Report findings** with severity (CRITICAL / HIGH / MEDIUM / LOW)

## 12. Common SEO mistakes to flag

- ❌ Duplicate titles across pages
- ❌ Missing meta descriptions
- ❌ H1 includes the site name ("Privacy Score | Home") — keep H1 focused on the page topic
- ❌ Image alt = filename ("hero-2.png") — must be descriptive
- ❌ JSON-LD injected via `<script>` after page load
- ❌ Canonical pointing to a different language version
- ❌ hreflang pointing to a redirect (must point to the FINAL URL)
- ❌ Missing trailing-slash consistency
- ❌ Internal links using full URLs (use relative URLs)
