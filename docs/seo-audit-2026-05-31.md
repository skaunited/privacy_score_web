## 1. Executive Summary

### Overall verdict: **NOT READY** for a full pre-launch / GSC submit / press push.

The site is well-built at the structural level (clean Astro static output, full i18n parity, JSON-LD parses, sitemap correct, security.txt present, no third-party trackers in HTML) but has **six pre-launch blockers** that any of the targeted search engines (Google, Bing, DuckDuckGo, Brave, Ecosia, Qwant, plus AI surfaces — Perplexity, ChatGPT Search, Bing Copilot, Brave Leo, Google AI Overviews) will pick up and penalize.

In particular: the site **is already live and indexed by Google** at `https://www.privacyscore.fr` (we found it ranking #1–#2 for brand queries in fr-FR Google) — but with **canonical/www-vs-non-www mismatch**, **outdated content vs. local dist** (the recent em-dash sweep has not been deployed), **render-blocking Google Fonts pulled from 3rd-party CDN** (privacy contradiction), and **dead `#download` CTAs everywhere**. Publishing to GSC in this state will lock those issues into Google's index for weeks.

**Site-wide `www` issue (CRITICAL):**
- `astro.config.mjs` declares `site: 'https://privacyscore.fr'` (no www)
- All canonicals + og:url + sitemap entries use the no-www form
- BUT the live deploy at Cloudflare serves `https://www.privacyscore.fr/fr/` (verified via DataForSEO `on_page_instant_pages` — `final_url` and `is_www: true`)
- And Google has already indexed the WWW form (verified via SERP — branded search returns `https://www.privacyscore.fr/en/` at rank #1)

Result: Googlebot sees `og:url=https://privacyscore.fr/...` and `canonical=https://privacyscore.fr/...` but is being served from `www.privacyscore.fr/...`. This is a textbook canonical conflict.

**Fix (pick one):**
- Option A (recommended): keep no-www. Add a 301 redirect from `www.privacyscore.fr/*` → `privacyscore.fr/$1` in Cloudflare DNS Page Rules / Nginx config. Re-deploy. Resubmit sitemap.
- Option B: switch the entire site to www. Change `SITE` constant in `astro.config.mjs` and `src/i18n/utils.ts:SITE_ORIGIN` to `https://www.privacyscore.fr`. Rebuild. Add a 301 from non-www to www.

**Fix proposal (homepages):** Add an H1 that carries the keyword without breaking the brand voice. Two patterns work:

Pattern A — H1 carries the brand + benefit, the dramatic punchline demotes to H2:
```html
<h1>Privacy Score : votre audit de confidentialité iPhone, en local.</h1>
<h2 class="hero-strike">Vous pensez être anonyme. Vous ne l'êtes pas.</h2>
```

Pattern B — visually-hidden H1 carries the keyword for crawlers, leaves the dramatic visual H1 intact:
```html
<h1 class="visually-hidden">Privacy Score — audit de confidentialité iPhone à partir du Rapport iOS.</h1>
<p class="hero-title-display">Vous pensez être anonyme. Vous ne l'êtes pas.</p>
```

Pattern A is preferred — Google has historically penalized invisible H1s as cloaking-adjacent.
