## Configuration constatée

- Le module Apache `remoteip_module` est chargé.
- Le binaire Nginx du serveur inclut `--with-http_realip_module`.
- La configuration Apache Plesk utilise déjà `RemoteIPHeader X-Forwarded-For` avec le proxy interne `127.0.0.1`.
- Nginx transmet `X-Real-IP $remote_addr` et `X-Forwarded-For $proxy_add_x_forwarded_for` vers Apache.
- La configuration Nginx effective ne contient actuellement aucun `real_ip_header`, `set_real_ip_from` ou `real_ip_recursive`.
- Les champs Additional Apache directives du domaine sont vides. Les directives Nginx additionnelles sont celles générées par le dépôt ; elles ne nécessitent pas de remplacement pour cette correction.
- Aucune plage Cloudflare n’est actuellement dans la liste d’exclusion Fail2Ban consultée.

La chaîne actuelle journalise donc le relais Cloudflare comme visiteur. Une détection GPTBot peut bannir un relais utilisé ensuite par des visiteurs ordinaires ou d’autres robots. Cela correspond à la [cause d’erreur 521 décrite par Cloudflare](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-521/).
